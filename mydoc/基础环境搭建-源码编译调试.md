# miniconda安装
## 下载Miniconda安装脚本
```shell
# 使用清华镜像源加速下载,aarch64版本
wget https://mirrors.tuna.tsinghua.edu.cn/anaconda/miniconda/Miniconda3-latest-Linux-aarch64.sh
# x86_64版本
wget https://mirrors.tuna.tsinghua.edu.cn/anaconda/miniconda/Miniconda3-latest-Linux-x86_64.sh
```


## 安装与初始化

下载完成后，按以下步骤执行安装：

1.  运行安装脚本：使用bash命令运行脚本。
    bash Miniconda3-latest-Linux-aarch64.sh
    

2.  遵循安装提示：
    ?   按 Enter 浏览许可协议，然后输入 yes 同意条款。

    ?   确认安装路径，通常直接按 Enter 使用默认路径 ~/miniconda3 即可。

    ?   关键一步：当安装程序询问 Do you wish the installer to initialize Miniconda3 by running conda init? 时，请务必输入 yes。这一步会自动将Conda的初始化代码添加到你的shell配置文件（如 ~/.bashrc）中，这是后续能直接使用 conda 命令的保障。

3.  激活安装：安装完成后，你需要让配置生效。最简单的方法是关闭当前终端，然后重新打开一个新终端。你会发现命令提示符前出现了 (base) 字样，这表示Miniconda的base环境已激活。

4.  验证安装：在新终端中执行以下命令，如果显示Conda版本号，则说明安装成功。
    conda --version

# GPU服务器jax的编译安装和调试
## 使用pip 安装（非源码编译）
```bash
conda create --name jax_rel python=3.11
conda activate jax_rel
pip install --upgrade "jax[cuda12]"
```
## 源码编译安装
1. 登入阿里云开启vncserver，通过vncviewer连接到云服务器，开启clash允许代理

2. 进入调试服务器，安装虚拟环境并激活
```bash
conda create --name jax_debug python=3.13
conda activate jax_debug
```
3. 通过代码，获取源码

```bash
export https_proxy=http://120.77.201.177:7897
git clone https://github.com/jax-ml/jax
cd jax
git clone https://github.com/openxla/xla
```

4. 修改.bazelrc，增加代理配置
```shell
# Proxy settings for network access
common --action_env=http_proxy=http://120.77.201.177:7897
common --action_env=https_proxy=http://120.77.201.177:7897
common --action_env=HTTP_PROXY=http://120.77.201.177:7897
common --action_env=HTTPS_PROXY=http://120.77.201.177:7897
common --action_env=ALL_PROXY=http://120.77.201.177:7897
common --action_env=all_proxy=http://120.77.201.177:7897
```

5. 构建
- 方式1(生成wheel包)
    ```shell
    python build/build.py build --wheels=jaxlib,jax-cuda-plugin,jax-cuda-pjrt --bazel_options=--compilation_mode=dbg --bazel_options=--copt=-g --bazel_options=--copt=-O0 --bazel_options=--strip=never --bazel_options=--override_repository=xla=$(pwd)/xla --local_xla_path=$(pwd)/xla
    ```
- 方式2(使用editable模式，增加了--editable配置参数,建议采用此方式,后面修改源码后只需要重新编译不需要重新安装即可生效)：
    ```shell
    python build/build.py build --wheels=jaxlib,jax-cuda-plugin,jax-cuda-pjrt --editable --bazel_options=--compilation_mode=dbg --bazel_options=--copt=-g --bazel_options=--copt=-O0 --bazel_options=--strip=never --bazel_options=--override_repository=xla=$(pwd)/xla --local_xla_path=$(pwd)/xla
    ```
- 错误处理,可能遇到以下错误：
    ```shell
    PermissionError: [Errno 13] Permission denied: '/tmp/nvcc_wrapper.txt'
    Target //jaxlib/tools:jax_cuda12_plugin_wheel_editable failed to build
    INFO: Elapsed time: 3.902s, Critical Path: 0.20s
    INFO: 193 processes: 172 internal, 21 local.
    ERROR: Build did NOT complete successfully
    ```
错误原因可能是'/tmp/nvcc_wrapper.txt'是别的用户创建的，用sudo权限把它删除即可。

6. 安装
- 方式1编译后安装wheel包：
    ```shell
    pip install dist/jaxlib-0.9.1.dev0+selfbuilt-cp313-cp313-manylinux_2_27_x86_64.whl dist/jax_cuda12_plugin-0.9.1.dev0+selfbuilt-cp313-cp313-manylinux_2_27_x86_64.whl dist/jax_cuda12_pjrt-0.9.1.dev0+selfbuilt-py3-none-manylinux_2_27_x86_64.whl

    pip install -e .
    ```


- 方式2编译安装(有顺序要求)：
    ```shell
    python -m pip install -e dist/jaxlib
    python -m pip install -e dist/jax_cuda12_pjrt
    python -m pip install -e dist/jax_cuda12_plugin
    python -m pip install -e .
    ```

## jax调试
vscode 安装CodeLLDB(最好是最新版本，从github上下载，手动安装：wget https://github.com/vadimcn/codelldb/releases/download/v1.12.0/codelldb-x86_64-linux.vsix)

使能ptrace:
```shell
sudo sysctl -w kernel.yama.ptrace_scope=0
```
vscode找开jax目录，执行调试
vscode配置(关键是sourceMap的源代码映射正确，否则断点可能不生效)：
```json
{
    "version": "0.2.0",
    "configurations": [
         {
            "type": "lldb",
            "request": "attach",
            "name": "Attach",
            "pid": "${command:pickMyProcess}",
            "sourceMap": {
                "/proc/self/cwd/external/xla": "${workspaceFolder}/xla",
                "/proc/self/cwd": "${workspaceFolder}",
                "/proc/self/cwd/external":"${workspaceFolder}/bazel-jax/external"
            },
            "stopOnEntry": false
        },

        {
            "name": "Python Debugger: Current File",
            "type": "debugpy",
            "request": "launch",
            "program": "${file}",
            "console": "integratedTerminal",
            "justMyCode": false,
        }
    ]
}
```
bazel编译后，对于当前路径在调试信息中映射成/proc/self/cwd,因此当vscode的工程路径就是jax时，要配置sourceMap为："/proc/self/cwd": "${workspaceFolder}"，对于外部依赖库，比如xla,llvm等库的源码路径会映射为为/proc/self/cwd/external，因此我们使用的xla源码路径被映射为/proc/self/cwd/external/xla，因此需要配置sourceMap为："/proc/self/cwd/external/xla": "${workspaceFolder}/xla"。
如果在调试c++代码时断点不生效，请留意在调试过程打开的汇编文件的断点，汇编文件开头都会注明源代码路径，比如我在pjrt::LoadPjrtPlugin函数处进行单步进入时，由于lldb找不到源码，会进入一个汇编文件的某个指令，我们观察这个汇编文件开头的源代码路径就可以指导我们如何完成源代码映射。如下所示：
