```python
def matmul_with_elementwise(x, y):
    """矩阵乘法与 element-wise 操作的组合"""
    # 矩阵乘法通常会触发 Triton 优化
    matmul_result = jnp.matmul(x, y)
    # 后续的 element-wise 操作应该与矩阵乘法融合
    activated = jnp.tanh(matmul_result)
    scaled = jnp.multiply(activated, 2.0)
    biased = jnp.add(scaled, 0.1)
    return biased
```

# XLA 编译流程
- XLA接收StableHLO,首先通过MllirToHloModule函数将StableHLO转换成转换为 XLA 可以执行的计算表示XlaComputation
- 对应多层的转换架构StableHLO → MHLO → HLO -> HloProto → HloModule -> XlaComputation
- HloProto和HloModule的关系请参考[HloProto和HloModule的关系.md](./xla/xla/hlo/ir/HloProto和HloModule的关系.md)
## MlirToXlaComputation
- 请参考[MlirToXlaComputation函数解析.md](./xla/xla/pjrt/mlir_to_hlo.cc/MlirToXlaComputation函数解析.md)，转换过程：
  - 1. 完成一些优化转换，转换后的IR内容如下：
    ```c++
        module @jit_matmul_with_elementwise attributes {mhlo.num_partitions = 1 : i32, mhlo.num_replicas = 1 : i32} {
      func.func public @main(%arg0: tensor<1x32x32xf32>, %arg1: tensor<1x32x32xf32>) -> (tensor<1x32x32xf32> {jax.result_info = "result"}) {
        %cst = stablehlo.constant dense<1.000000e-01> : tensor<f32>
    ```
